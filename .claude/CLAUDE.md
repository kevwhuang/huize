# Huize

Corporate website for 惠泽健康 (Huize Health), a Shanghai digital health company linking insurers, enterprises, and individuals to elderly care, rehabilitation, nursing, and health management across 530 cities. Features twenty-one Chinese-first pages served from a JSON content database keyed by deterministic UUIDs for a future Supabase table, a dev-only inline editor with color-coded targets and batch undo and redo, five JSON content APIs, and self-hosted Chinese webfonts sliced by unicode range. Built with Astro, TypeScript, Tailwind CSS, and GSAP. Deployed on Netlify.
